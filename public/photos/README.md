# Photos

Drop photos here using the file names from `data/photos.ts`. Each slot on
the site switches from its labelled placeholder to the real image on the
next build.

| File | Where it appears |
| --- | --- |
| `hero.jpg` | Home: full-screen opening shot (landscape, ~2400px wide) |
| `ritual-sift.jpg`, `ritual-pour.jpg`, `ritual-whisk.jpg` | Home: "The ritual" triptych (portrait 4:5) |
| `tea-field.jpg` | Home: dark "tea field" chapter (landscape, calm) |
| `interior.jpg` | Book page, beside the form (4:3) |
| `about-bar.jpg` | About page (portrait 4:5) |
| `menu/<item-id>.jpg` | Home featured cards + menu hover previews, e.g. `menu/cardamom-bun.jpg` (portrait 3:4) |

Menu item ids are the `id` values in `data/menu.ts`.

Style: natural window light, hands in frame, shallow depth of field, no faces
to camera. The site applies a gentle warm grade to every photo, so small
differences between shoots or stock images even out.

If you use stock images, use ones licensed for commercial use (e.g. Unsplash
or Pexels licence) and note the source below.
